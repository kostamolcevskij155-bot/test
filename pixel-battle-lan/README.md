# PIXEL BATTLE LAN

Упрощённый клон **r/place** для локальной сети. Сервер на Node.js + Express +
Socket.IO, клиент — чистый HTML/CSS/JS, холст хранится **в памяти**
(без баз данных). Никаких внешних сервисов и CDN — всё работает «из коробки».

## Структура проекта

```
pixel-battle-lan/
├── package.json        # зависимости: express + socket.io
├── server.js           # сервер: холст в памяти, Socket.IO, кулдаун
└── public/
    ├── index.html      # разметка клиента
    ├── style.css       # стили клиента
    └── client.js       # логика клиента (canvas, палитра, оверлей)
```

## Что умеет

- Холст **100×100** пикселей (меняется константой `SIZE` в `server.js`);
- Real-time синхронизация: пиксель одного игрока мгновенно виден всем;
- Новый клиент при подключении получает **весь холст целиком**;
- Кулдаун **2 сек** на пиксель (по `socket.id`, константа `COOLDOWN_MS`);
- Палитра из **20 цветов**, горячие клавиши `1–9, 0`;
- Панорама перетаскиванием, зум колесом и pinch-зум на телефоне;
- **Оверлей**: загрузка локальной картинки полупрозрачным слоем поверх холста,
  чтобы обводить её пикселями (только на клиенте, на сервер не уходит);
- Лента событий, счётчик «онлайн», скачивание холста в PNG;
- Сервер при старте сам печатает LAN-адреса машины.

## Требования

- [Node.js](https://nodejs.org) версии 16 или новее (проверка: `node -v`).

## Запуск — вариант 1 (готовые файлы)

Файлы проекта уже содержат `package.json`, поэтому достаточно:

```bash
cd pixel-battle-lan
npm install        # поставит express и socket.io в папку node_modules
npm start          # запустит сервер на 0.0.0.0:3000
```

## Запуск — вариант 2 (с нуля)

Если собираете проект вручную в пустой папке:

```bash
mkdir pixel-battle-lan && cd pixel-battle-lan
mkdir public               # сюда положите index.html, style.css, client.js
npm init -y                # создаст package.json
npm install express socket.io
npm start                  # либо: node server.js
```

После запуска в консоли появится примерно такое:

```
  ╔══════════════════════════════════════════════╗
  ║        PIXEL BATTLE LAN — сервер запущен      ║
  ╚══════════════════════════════════════════════╝
  Холст:      100×100 пикселей (в памяти)
  Кулдаун:    2000 мс на пиксель
  Локально:   http://localhost:3000
  В сети LAN: http://192.168.1.42:3000  (интерфейс en0)
```

## Как узнать свой локальный IP

Сервер печатает адрес сам, но вот команды для каждой системы:

**Windows**

```bash
ipconfig
```

Ищите строку **«IPv4-адрес»** у активного адаптера (Wi-Fi/Ethernet),
например `192.168.1.42`. Если брандмауэр спросит разрешение для Node.js —
разрешите доступ для частных сетей.

**macOS**

```bash
ipconfig getifaddr en0     # Wi-Fi (попробуйте en1, если пусто)
```

**Linux**

```bash
hostname -I                # или: ip -4 addr show | grep inet
```

## Подключение других устройств

Все устройства должны быть в **одной локальной сети** (один Wi-Fi/роутер).

1. На самой машине-сервере откройте `http://localhost:3000`.
2. На телефоне/планшете/ноутбуке откройте `http://<ваш-IP>:3000`,
   например `http://192.168.1.42:3000`.

Если страница не открывается: проверьте, что машина-сервер не в «спящем»
режиме, что устройства в одной подсети, и что брандмауэр/антивирус не
блокирует порт **3000** (в Linux: `sudo ufw allow 3000`).

## Настройка

В начале `server.js`:

| Константа     | По умолчанию | Что делает                        |
|---------------|--------------|-----------------------------------|
| `PORT`        | `3000`       | порт сервера                      |
| `SIZE`        | `100`        | сторона холста в пикселях         |
| `COOLDOWN_MS` | `2000`       | кулдаун на пиксель, миллисекунды  |
| `MAX_COLOR`   | `19`         | макс. индекс палитры (длина − 1)   |

> Холст живёт в оперативной памяти: перезапуск сервера очистит рисунок.
> При желании состояние легко сохранять в файл (`fs.writeFileSync` с
> JSON-дампом массива) — это единственное, что намеренно не добавлено,
> чтобы проект оставался минимальным.

## Примечания

- Оверлей обрабатывается **только в браузере клиента** и никогда не
  отправляется на сервер.
- Аутентификации нет — это игрушка для доверенной локальной сети.
- Клиентская библиотека Socket.IO отдаётся самим сервером
  (`/socket.io/socket.io.js`), интернет не нужен.
